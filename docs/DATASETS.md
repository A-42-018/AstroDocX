# AstroDocX: datasets and data sources

Every dataset, reference source and third-party asset the AstroDocX website uses (landing page, Crew Console, 3D cabin, VITA), what each one is used for, and how well its provenance is recorded. Written 7 Nov 2026 from the code and the live OSDR API.

**Short version:** exactly one measured astronaut dataset is used as data (NASA OSDR Inspiration4 blood tables). Everything the console computes live is synthetic. NASA studies, reports and standards are cited as evidence and limits. The 3D models and textures are third-party art assets, not datasets.

## 1. Measured data (the only real astronaut measurements)

| Dataset | Publisher | What we take | Where it shows | Licence / terms |
|---|---|---|---|---|
| **OSD-569** Whole Blood, SpaceX Inspiration4: `LSDS-7_Complete_Blood_Count_CBC_TRANSFORMED.csv` | NASA OSDR (released 14 May 2024) | White blood cells, absolute lymphocytes, absolute neutrophils, platelets, hemoglobin: 4 anonymised crew × 7 timepoints (3 before launch, 4 after landing), with lab reference ranges. 135 values. | Console → NASA Data → "Real crew data" | NASA open data; cite OSD-569 and the Inspiration4 paper (doi:10.1038/s41586-024-07639-y) |
| **OSD-575** Blood Serum, SpaceX Inspiration4: `LSDS-8_Comprehensive_Metabolic_Panel_CMP_TRANSFORMED.csv` | NASA OSDR | Glucose, calcium, alkaline phosphatase (4 × 7, with reference ranges). 84 values. | same | same |
| **OSD-575**: `LSDS-8_Multiplex_serum_cardiovascular_EvePanel_TRANSFORMED.csv` | NASA OSDR | C-reactive protein, fibrinogen (4 × 7). Research multiplex assay, no clinical reference range. 56 values. | same | same |

Handling, all in `tools/bake-i4-labs.mjs` (output `app/src/nasa/i4-labs.json`, 275 values):
- **One source row is left out.** NASA's own table for crew member C003 at 92 days before launch has an impossible blood count (mean platelet volume 330 fL, RDW 32.4 %, platelets 12.9, neutrophils 10.1 cells/µL next to 71 % neutrophils). It is excluded and the panel says so.
- CRP is converted from pg/mL to mg/L (exact). Fibrinogen stays in ng/mL, because the multiplex readout is a diluted research assay and a clinical conversion would mislead.
- Crew stay anonymised (C001–C004). Four people on a three-day flight is a case series, not a norm; the panel presents it as context, never a diagnosis.

### The ten Inspiration4 records in OSDR (all listed on the NASA Data screen)

| OSD | Content | Used? |
|---|---|---|
| 569 | Whole blood: CBC, RNA-seq, WGS | **CBC table used as data**; sequencing not used |
| 570 | PBMC single-nucleus RNA/ATAC, T/B-cell repertoire | Cited only |
| 571 | Plasma proteomics, metabolomics, cfDNA/cfRNA | Cited only |
| 572 | Crew oral, nasal, skin microbiome swabs | Cited only |
| 573 | Dragon capsule surface microbes (environment) | Cited only |
| 574 | Deltoid skin spatial transcriptomics and microbiome | Cited only |
| 575 | Serum metabolic panel and cytokine arrays | **CMP and cardiovascular tables used as data**; immune panels not used |
| 630 | Stool metagenome | Cited only |
| 656 | Urine inflammation panel (small CSV, a candidate for later) | Cited only |
| 687 | T-cell histone modifications (raw files restricted) | Cited only |

Why the rest are not used: they are sequencing, microbiome and similar omics files (MB to GB) with no per-person health reading the console could chart.

**Not available in these datasets:** heart rate, HRV, SpO₂, sleep and other wearable series. OSDR does not carry them, so the console's vitals stay synthetic.

## 2. Synthetic data (generated by the app, not collected)

| Data | Generated by | Used for |
|---|---|---|
| 4-crew, 30-day demo mission: 11 metrics (HR, HRV, SpO₂, sleep, exercise, reaction time, mood, cabin CO₂, cabin temperature, noise, radiation dose) | `app/src/data/synthetic.ts`, seeded PRNG (mulberry32), mission start fixed at 2030-01-01 so output is byte-identical | Status Board, Trends, Alerts, Doctor, Simulator, Ground View, the landing page's Health Twin panels and Crew Readiness |
| Baselines, alerts and action log for that mission | `app/src/data/demo-snapshot.json`, checked against a fresh engine run by `demo.snapshot.test.ts` | Fast first load |
| Four injectable scenarios (solar event, CO₂ fault, insomnia, deconditioning) | `app/src/sim/` | Mission Simulator |
| Daily check-in answers, reaction test | The user, stored on the device in IndexedDB | Check-in, alerts |

The console labels the live waves `SIM`. Thresholds that are not cited are labelled illustrative.
